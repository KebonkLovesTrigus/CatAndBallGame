# CatAndBallGame
A game for a school project.
Welcome to the cat and ball game. The goal of the game is to find Whiskas(cat food).
The game is played by guessing the position of the target in a NxN area. You can decide
how wide the map is at the start. If you guess wrongly, a number will appear showing you
how many Whiskas are around the area you guessed wrongly. You can also obtain an extra life
if you are lucky. Extra lives are labelled B(ball) and whiskas is W. Note that no matter how
big the map is, you only have 3 lives. Good luck!
